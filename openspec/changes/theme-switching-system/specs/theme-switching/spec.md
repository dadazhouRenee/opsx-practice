## ADDED Requirements

### Requirement: 用户可以在浅色和深色模式间切换

系统必须提供明暗主题切换功能，允许用户在浅色模式和深色模式之间选择。用户的选择必须立即生效并持久化保存。

#### Scenario: 用户切换到深色模式
- **WHEN** 用户点击 Header 中的主题切换按钮（当前为浅色模式）
- **THEN** 系统立即切换到深色模式，所有 UI 组件的颜色方案更新为深色
- **THEN** 用户的选择保存到 localStorage
- **THEN** 切换按钮图标更新为月亮图标

#### Scenario: 用户切换到浅色模式
- **WHEN** 用户点击 Header 中的主题切换按钮（当前为深色模式）
- **THEN** 系统立即切换到浅色模式，所有 UI 组件的颜色方案更新为浅色
- **THEN** 用户的选择保存到 localStorage
- **THEN** 切换按钮图标更新为太阳图标

#### Scenario: 页面加载时恢复用户的主题偏好
- **WHEN** 用户刷新页面或重新访问系统（之前选择过深色模式）
- **THEN** 系统从 localStorage 读取用户的主题偏好
- **THEN** 页面以深色模式渲染，无明显闪烁

#### Scenario: 首次访问用户使用默认主题
- **WHEN** 用户首次访问系统（localStorage 中无主题记录）
- **THEN** 系统使用默认的浅色模式
- **THEN** Header 中的切换按钮显示太阳图标

### Requirement: 用户可以选择主题颜色

系统必须提供主色调选择器，允许用户从 4 种预设颜色（蓝色、绿色、紫色、橙色）中选择主题颜色。主色调影响按钮、链接、选中状态等强调色的显示。

#### Scenario: 用户选择绿色主题
- **WHEN** 用户在 `/settings` 页面点击绿色主题按钮
- **THEN** 系统立即将主色调切换为绿色
- **THEN** 所有使用 primary 颜色的组件（按钮、链接、选中边框等）更新为绿色
- **THEN** 用户的选择保存到 localStorage
- **THEN** 绿色按钮显示选中状态（边框高亮）

#### Scenario: 用户切换不同主题颜色
- **WHEN** 用户当前使用蓝色主题，点击紫色主题按钮
- **THEN** 系统立即将主色调从蓝色切换为紫色
- **THEN** 所有 primary 颜色的组件实时更新
- **THEN** 紫色按钮显示选中状态，蓝色按钮恢复非选中状态

#### Scenario: 页面加载时恢复用户的颜色偏好
- **WHEN** 用户刷新页面或重新访问系统（之前选择过橙色主题）
- **THEN** 系统从 localStorage 读取用户的颜色偏好
- **THEN** 页面以橙色主题渲染

#### Scenario: 首次访问用户使用默认颜色
- **WHEN** 用户首次访问系统（localStorage 中无颜色记录）
- **THEN** 系统使用默认的蓝色主题
- **THEN** 蓝色按钮显示选中状态

### Requirement: 主题颜色和明暗模式独立控制

用户必须能够独立选择主题颜色和明暗模式，两者的组合产生不同的视觉效果（4 种颜色 × 2 种模式 = 8 种组合）。

#### Scenario: 用户在深色模式下切换主题颜色
- **WHEN** 系统当前为深色模式 + 蓝色主题
- **WHEN** 用户在 `/settings` 页面切换到绿色主题
- **THEN** 系统保持深色模式，仅主色调变为绿色
- **THEN** 背景、文字等中性色保持深色风格

#### Scenario: 用户在选定颜色后切换明暗模式
- **WHEN** 系统当前为浅色模式 + 紫色主题
- **WHEN** 用户点击 Header 的主题切换按钮切换到深色模式
- **THEN** 系统切换到深色模式，主色调保持紫色
- **THEN** 背景、文字等中性色切换为深色风格，紫色主色调依然可见
