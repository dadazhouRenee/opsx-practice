## ADDED Requirements

### Requirement: 系统必须提供主题设置页面

系统必须在 `/settings` 路由提供主题设置页面，允许用户配置明暗模式和主题颜色。页面必须包含主题配置区域和组件预览区域。

#### Scenario: 访问设置页面
- **WHEN** 用户访问 `/settings` 路由
- **THEN** 系统显示主题设置页面
- **THEN** 页面标题显示"主题设置"
- **THEN** 页面描述显示"自定义系统外观和颜色"

#### Scenario: 页面包含主题配置区域
- **WHEN** 用户查看设置页面
- **THEN** 页面显示"主题配置"卡片
- **THEN** 卡片内包含明暗模式选择器
- **THEN** 卡片内包含主题颜色选择器

#### Scenario: 页面包含组件预览区域
- **WHEN** 用户查看设置页面
- **THEN** 页面显示"组件预览"卡片
- **THEN** 卡片内展示多种 UI 组件的当前主题效果

### Requirement: 明暗模式选择器必须提供可视化切换界面

设置页面必须提供明暗模式选择器，显示浅色和深色两个选项按钮。用户点击按钮后立即切换模式，当前选中的模式必须显示视觉反馈。

#### Scenario: 显示明暗模式选择器
- **WHEN** 用户查看主题配置区域
- **THEN** 区域显示"明暗模式"标签
- **THEN** 区域显示两个按钮："浅色"和"深色"
- **THEN** 浅色按钮显示太阳图标，深色按钮显示月亮图标

#### Scenario: 当前模式显示选中状态
- **WHEN** 系统当前为浅色模式
- **THEN** 浅色按钮显示选中状态（背景高亮或边框强调）
- **THEN** 深色按钮显示非选中状态

#### Scenario: 点击按钮切换模式
- **WHEN** 用户点击深色按钮（当前为浅色模式）
- **THEN** 系统切换到深色模式
- **THEN** 深色按钮显示选中状态
- **THEN** 浅色按钮恢复非选中状态
- **THEN** 页面上的所有组件预览立即更新为深色风格

### Requirement: 主题颜色选择器必须提供可视化颜色按钮

设置页面必须提供主题颜色选择器，以网格布局显示 4 个颜色按钮（蓝色、绿色、紫色、橙色）。每个按钮必须使用对应的主题颜色作为背景，并显示颜色名称标签。

#### Scenario: 显示主题颜色选择器
- **WHEN** 用户查看主题配置区域
- **THEN** 区域显示"主题颜色"标签
- **THEN** 区域显示 4 个颜色按钮，排列为 2 行 2 列的网格
- **THEN** 每个按钮背景色为对应的主题颜色
- **THEN** 每个按钮显示中文颜色名称："蓝色"、"绿色"、"紫色"、"橙色"

#### Scenario: 当前颜色显示选中状态
- **WHEN** 系统当前使用蓝色主题
- **THEN** 蓝色按钮显示选中状态（边框高亮和缩放效果）
- **THEN** 其他颜色按钮显示非选中状态

#### Scenario: 点击颜色按钮切换主题
- **WHEN** 用户点击绿色按钮（当前为蓝色主题）
- **THEN** 系统切换到绿色主题
- **THEN** 绿色按钮显示选中状态
- **THEN** 蓝色按钮恢复非选中状态
- **THEN** 页面上的所有组件预览立即更新为绿色强调色

#### Scenario: 颜色按钮提供 hover 反馈
- **WHEN** 用户鼠标悬停在非选中的颜色按钮上
- **THEN** 按钮显示轻微放大效果（scale-105）
- **THEN** 鼠标移出后恢复原始大小

### Requirement: 组件预览区域必须展示多种 UI 组件

设置页面必须提供组件预览区域，展示按钮、下拉选择、Alert 消息、卡片等常用 UI 组件在当前主题下的视觉效果。预览组件必须实时响应主题切换。

#### Scenario: 显示按钮预览
- **WHEN** 用户查看组件预览区域
- **THEN** 区域显示"按钮样式"标签
- **THEN** 区域显示多个按钮变体：默认、次要、边框、危险、幽灵
- **THEN** 每个按钮使用当前主题的相应样式

#### Scenario: 显示下拉选择预览
- **WHEN** 用户查看组件预览区域
- **THEN** 区域显示"下拉选择"标签
- **THEN** 区域显示一个 Select 组件，占位符为"选择一个选项"
- **THEN** 用户点击 Select 后弹出选项列表（选项 1、选项 2、选项 3）

#### Scenario: 显示 Alert 消息预览
- **WHEN** 用户查看组件预览区域
- **THEN** 区域显示"Alert 消息"标签
- **THEN** 区域显示信息类型的 Alert（蓝色图标 + 提示文字）
- **THEN** 区域显示警告类型的 Alert（黄色图标 + 警告文字）

#### Scenario: 显示卡片预览
- **WHEN** 用户查看组件预览区域
- **THEN** 区域显示"卡片样式"标签
- **THEN** 区域显示一个嵌套的示例卡片
- **THEN** 卡片包含标题、描述和内容文本

#### Scenario: 预览组件响应主题切换
- **WHEN** 用户在设置页面切换到紫色主题
- **THEN** 所有预览组件中使用 primary 颜色的部分更新为紫色
- **THEN** 默认按钮的背景色变为紫色
- **THEN** Select 组件的 focus 边框变为紫色
- **THEN** 信息 Alert 的图标和边框变为紫色

#### Scenario: 预览组件响应明暗模式切换
- **WHEN** 用户在设置页面切换到深色模式
- **THEN** 所有预览组件的背景和文字颜色切换为深色风格
- **THEN** 卡片背景变为深色
- **THEN** Alert 背景和文字颜色适配深色模式
- **THEN** 按钮和 Select 组件使用深色模式的样式变体
